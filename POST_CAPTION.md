Built a production-shaped SRE portfolio project: `prometheus-slo-alert-lab`.

It evaluates Prometheus-style SLO burn rates, routes incidents as page/ticket/ok, emits JSON and Markdown reports, exposes a FastAPI service with Prometheus metrics, and includes Docker, Kubernetes, Terraform, tests, and CI-ready docs.

This was a useful way to show practical platform engineering work beyond toy scripts: error-budget reasoning, incident response automation, observability, container packaging, and deployment manifests in one runnable repo.
